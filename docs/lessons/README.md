# 讲义索引 · 按日执行入口

每天只做一件事：**打开当周文件，跳到今天那一节**。每节固定七段——本质 → Java 视角 → 核心讲解 → 代码 → 今天的动作 → 会踩的坑 → 自测。

单节设计时长 45 分钟（另加 5 分钟回顾、10 分钟落盘）。看不完就砍范围，不要延到第二天，也不要占用周日。

## 三条不变规则

1. 讲义里的"今天的动作"是范围上限，不是下限。做不完就砍，别加时段。
2. 代码是参照，不是你今天的全部产出——**必须自己敲一遍**，抄过去的代码三天后归零。
3. 周日不打开仓库。这条被破坏的代价是后面五天全部失效。
